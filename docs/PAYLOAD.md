# Payload CMS

Paneles:

1. Administración interna:
   - usuarios
   - recintos
   - proveedores
   - actividades
   - sincronizaciones
   - conciliación
   - incidencias

2. Teatro:
   - solo sus actividades
   - disponibilidad
   - emisiones
   - incidencias propias

3. ICUB:
   - lectura
   - métricas
   - actividad
   - conciliación
   - sin edición operativa

La autorización debe hacerse en servidor. Ocultar botones en la UI no es control de acceso.
